    二次开发 / 扩展说明
        
    源码按注册表组织：MODELS（模型与参数定义、例题）、CHARTS（图表）、METRICS（扫描指标）、PROMPTS（提示词）、AI.PRESETS（供应商预设）。新增一条记录即可出现在界面与 AI 提示词中；物理求解集中在 solveContact()、simulate()（传送带 / 板块）与 simulateDuo()（两物块碰撞相遇）。解题过程在 solutionSteps()，力学分析箭头在 renderScene() 的 o.forces 分支。新模型可在 MODELS 条目里自带 simulate / build / normalize / pack，模拟结果对象可自带 resultRows / checks / solution / render2D / infoBox / tiles / names 等钩子（参考人船模型 MODELS.boat 与例题拼合 MODELS.combo）；拼合可用的阶段类型在 STAGE_TYPES 注册表里，新增一条（参数表 + make + judge）即可多一种阶段，画法在 renderChain()；3D 画法集中在 render3D()。
